Google stack — who does what

One Live mouth on Cloud Run. Firebase holds memory. AI Logic is text only. Studio tools stay offline.

1 · Child & parent surfaces

Firebase Hosting
Kid tablet + parent dashboard. Static UI. No API key in the browser.
Firebase Auth
Named profiles for the cup. Parent email later.
App Check
Required before any client AI Logic call (from 2 Nov 2026).

2 · The mouth (in-lesson)

Cloud Run · server.ts
Holds the WebSocket. Builds the start brief. Persists captions. Runs board tools.
Gemini Live
Speak / hear / captions. Voice picker. Language inferred from speech.
Live tool calling
Our functionDeclarations: fading board, set_topic, assess_child_reasoning. Not browser AI Logic Live.

3 · Memory, digest, knobs

Cloud Firestore
Profile, materials, programs, BKT, ledger, tasks, turns, aiDigest. The model forgets. This does not.
Firebase AI Logic · text
getGenerativeModel after the session. Structured JSON digest. Not a second Live socket.
Cloud Storage
Homework photo, writing paste, textbook PDF → Files API.
Remote Config
LIVE_MODEL, default voice, default 15 min. Change without redeploy.
GA4
Events only: intent_offered, intent_chosen. Never raw captions.

4 · Studio (not the mouth)

Firecrawl
Search + parse + scrape. Topic and files become a preview. Never a Live tool.
Confirm → generate
After the family confirms, Cloud Run writes materials then an age-mapped program under the learner.

Logos: official Google Cloud product icons + Icons8 color set. Higgsfield / Gamma / Firecrawl stay in the studio layer — search, parse, and scrape feed Firestore materials, not the 15-minute mouth.
