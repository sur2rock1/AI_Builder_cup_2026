## 5. Engineering and risk findings (not fixed — your decision)

1. **Auth/privacy:** deploy script defaults `DEMO_MODE=true` with `--allow-unauthenticated`. With that, any visitor can `GET /api/learners` and read every child's profile, and write to any. `/api/client-log` is unauthenticated. A judge who asks "a minor's data?" gets a bad answer today.
2. **Primary models time out:** 2026-10-09 log shows `profiler.summarizeSession` hitting the 20 s deadline on `gemini-3.8-flash` and `gemini-3.6-flash` and succeeding only on `gemini-3.1-flash-lite`; `gemini-3.6-flash` also "fetch failed" in the assessor. Latency/quality of the headline model path is unmeasured (T19 latency spike never run).
3. **Repo hygiene:** `backups/` (hundreds of JSON/ts snapshots) and `_to_delete/` are committed; 25 modified + untracked files incl. all of guided mode are **uncommitted**; an 18 MB `ananta-upload.zip` sits in the tree; `.env` holds several old API keys in comments (not tracked by git — rotate and delete them); `functions/` is a stale second API.
4. **Scope:** `server.ts` 1,888 lines, `App.tsx` 1,592; curriculum ingestion, quality gates, 3D, photos, guided mode, spaced review stub… for a 3-minute demo.
5. **Content:** Chapter 1 scorecard (30 Sep): 14/22 records with lint errors, 0/22 critic-reviewed, 74 pictures withheld. Later regeneration runs happened (D-2026-09-30-8) but no post-fix scorecard is recorded.
